# Msaidizi — Bilingual AI Student Assistant

A RAG chatbot that answers student questions (English or Kiswahili) using
retrieval grounded in real university documents: exam timetables, teaching
timetables, and the student handbook.

## 1. Prerequisites

- Python 3.10+ installed
- A free Google AI Studio account (for the Gemini API key)

## 2. Clone and set up a virtual environment

```bash
git clone <your-repo-url>
cd Msaidizi

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Get a Gemini API key

1. Go to [https://aistudio.google.com/](https://aistudio.google.com/) and sign in with a Google account.
2. Click **Get API key** → **Create API key**. No credit card needed for the free tier.
3. Copy the key — you'll need it in the next step.

## 5. Set up your environment variables

Create a file called `.env` in the project root (same folder as this README):

```bash
touch .env
```

Open `.env` and add your key:

```
GEMINI_API_KEY=your_actual_key_here
```

**Never commit `.env` to git.** It should already be listed in `.gitignore` — double check with:

```bash
cat .gitignore
```

It should contain at least:
```
.env
venv/
backend/chroma_db/
__pycache__/
```

## 6. Add your data files

Place your source documents in `data/raw/`:

```
data/raw/handbook.pdf
data/raw/Timetable/<your teaching timetable file>.xlsx
data/raw/Timetable/<your exam timetable file>.xlsx
```

> If your filenames differ from what's referenced in `backend/build_dataset.py`,
> update the paths there to match exactly (case-sensitive, spaces included).

## 7. Build the knowledge base

This processes your raw documents into chunks and saves them:

```bash
python backend/build_dataset.py
```

You should see output like:
```
Saved 177 chunks
  handbook: 3
  timetable: 167
  exams: 7
```

## 8. Ingest into the vector database

This embeds all chunks and stores them in a local Chroma database:

```bash
python backend/ingest.py
```

> If you ever change your source data, re-run **both** step 7 and step 8 to
> rebuild the database from scratch:
> ```bash
> rm -rf backend/chroma_db
> python backend/build_dataset.py
> python backend/ingest.py
> ```

## 9. Test the pipeline directly (optional but recommended)

Before launching the UI, confirm the backend works on its own:

```bash
python backend/pipeline.py
```

This runs a couple of hardcoded test questions and prints the answers.

## 10. Run the app

```bash
streamlit run frontend/app.py
```

This opens the chat interface in your browser at `http://localhost:8501`.
Ask a question in English or Kiswahili and confirm you get a grounded answer.

## Troubleshooting

| Problem | Likely cause |
|---|---|
| `FileNotFoundError` on a data file | Check the exact filename/casing with `find data/raw -iname "*keyword*"` and update the path in `build_dataset.py` |
| `429 RESOURCE_EXHAUSTED` from Gemini | You've hit the free-tier daily quota for that model. Check usage at [ai.dev/rate-limit](https://ai.dev/rate-limit); `gemini-3.1-flash-lite` has a much higher daily cap than `gemini-3.8-flash` |
| `503 UNAVAILABLE` from Gemini | Google's servers are temporarily overloaded — the pipeline auto-retries and falls back to other models; if it keeps happening, wait a few minutes and try again |
| Bot answers "I don't know" for something that should be in the data | Check `data/processed/chunks.json` to confirm that fact was actually extracted and chunked correctly |
| `AttributeError: 'Client' object has no attribute 'models'` | Two variables named `client` are colliding — make sure your Chroma client and Gemini client have distinct variable names (`chroma_client`, `gemini_client`) |

## Project structure

```
Msaidizi/
├── .env                    # your API key (not committed)
├── requirements.txt
├── data/
│   ├── raw/                 # source documents (PDF, xlsx, csv)
│   └── processed/           # chunks.json, generated by build_dataset.py
├── backend/
│   ├── extract.py           # handbook PDF text extraction
│   ├── chunking.py          # chunk_text() + faqs_to_chunks()
│   ├── parse_timetable.py   # weekly teaching timetable parser
│   ├── parse_exam_timetable.py  # exam timetable parser
│   ├── build_dataset.py     # combines all sources into chunks.json
│   ├── ingest.py             # embeds + stores chunks in Chroma
│   ├── pipeline.py            # retrieval + Gemini generation (answer())
│   └── chroma_db/              # generated vector database (not committed)
└── frontend/
    └── app.py                  # Streamlit chat interface
```
